Servidor Personal

Proyecto personal para utilizar servicios de Google desde un servidor privado alojado en Oracle Cloud.

El titular configura las integraciones y autoriza mediante OAuth los permisos necesarios para cada una. Los datos se utilizan únicamente para ejecutar esas integraciones en el servidor.

Este proyecto es de uso personal. No ofrece registro público ni utiliza los datos con fines publicitarios o comerciales.
