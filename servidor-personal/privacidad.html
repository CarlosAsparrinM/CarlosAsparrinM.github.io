Uso de los datos

Esta aplicación permite conectar servicios de Google configurados por el titular en su servidor privado de Oracle Cloud. El acceso se limita a los permisos OAuth que se muestran y autorizan para cada integración; la aplicación no obtiene automáticamente acceso a todos los datos de la cuenta.

Datos procesados

Según los permisos autorizados, Google puede proporcionar información básica de la cuenta y los datos necesarios para que funcionen las integraciones configuradas. También se utiliza un token OAuth para mantener la autorización.

Finalidad

Los datos se procesan únicamente para operar las integraciones que el titular configure en su servidor personal. No se usan para publicidad, elaboración de perfiles, venta ni finalidades comerciales.

Almacenamiento y conservación

Los tokens y los datos necesarios para las integraciones se procesan en el servidor privado. La información temporal, la caché y los registros se conservan según la configuración de los servicios y se eliminan cuando dejan de ser necesarios o cuando se revoca la autorización.

Compartición

Los datos no se venden. Google y los proveedores de infraestructura necesarios para alojar o transportar las conexiones pueden procesar información para prestar sus servicios, conforme a sus propias políticas.

Seguridad y revocación

El servidor está destinado al uso personal del titular y las conexiones se autorizan mediante OAuth. El titular puede revocar el acceso desde la configuración de permisos de su cuenta de Google .

Política de datos de Google

El uso de la información recibida de las API de Google se ajustará a la Política de Datos de Usuario de los Servicios de API de Google , incluidos los requisitos de Uso Limitado.
