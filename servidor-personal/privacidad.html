Política de Privacidad

Servidor Personal · Última actualización: 24 de octubre de 2026

1. Responsable

Carlos Asparrin Martin, proyecto personal sin fines comerciales. Contacto: asparrincarlos715@gmail.com.

2. Datos de Google a los que se accede

  • La dirección de correo de la cuenta de Google que autoriza la aplicación.
  • Metadatos de los archivos de Google Drive (nombre, tamaño y fechas).
  • El contenido de los archivos del Drive que el titular reproduce, con permiso de solo lectura (drive.readonly).
  • El token OAuth necesario para mantener la autorización.

3. Finalidad

Los datos se usan exclusivamente para que el titular del Drive reproduzca su propio contenido en su servidor Jellyfin privado. No se usan para publicidad, elaboración de perfiles, venta ni cesión a terceros.

4. Almacenamiento

El token se guarda en la configuración privada del servidor. Los archivos se leen de Google Drive y se almacenan temporalmente en una caché local para permitir la reproducción; esa caché se elimina automáticamente. No se crean copias permanentes ni se comparten archivos.

5. Terceros

No se venden ni ceden datos. Solo intervienen los proveedores de infraestructura necesarios para el funcionamiento: Google (Google Drive), Oracle Cloud (servidor), Cloudflare (túnel HTTPS) y Tailscale (acceso privado). No tienen acceso a los datos para fines propios.

6. Conservación

El token se conserva hasta que el titular revoque el acceso. La caché temporal se elimina según la configuración del servidor. Los registros técnicos se conservan como máximo 30 días.

7. Seguridad

El acceso al servidor está restringido al titular, se usa HTTPS y la autorización se realiza mediante OAuth. No existe registro público ni cuentas de terceros.

8. Derechos y revocación

Puedes revocar el acceso de la aplicación en myaccount.google.com/permissions. Para solicitar la eliminación de datos o resolver cualquier duda, escribe a asparrincarlos715@gmail.com.

9. Uso limitado

El uso de la información recibida de las API de Google se ajustará a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

10. Cambios

Cualquier cambio en esta política se publicará en esta misma página junto con la fecha de actualización.
